# دليل تشغيل برنامج MyAtelier Pro للمرة الأولى (غير المبرمجين) 🚀

مرحباً بك! هذا الدليل مخصص لك خصيصاً لتشغيل البرنامج على أي جهاز أو سيرفر جديد **دون الحاجة لكتابة أي سطر كود**. كل الأوامر والسكريبتات تم كتابتها وإعدادها سلفاً.

---

## 🛠️ المتطلبات الأساسية (قبل البدء)

تحتاج فقط إلى تثبيت برنامج **Docker** على الجهاز (إذا لم يكن مثبتاً).

### على نظام Ubuntu / Linux Mint:
افتح الشاشة السوداء (Terminal) وانسخ هذا الأمر كما هو ثم اضغط `Enter`:
```bash
curl -fsSL https://get.docker.com | sh && sudo usermod -aG docker $USER
```
*(ملاحظة: قم بإعادة تشغيل الجهاز بعد هذا الأمر أو إغلاق الشاشة السوداء وفتحها مجدداً).*

---

## ⚡ تشغيل البرنامج للمرة الأولى (في 3 خطوات بسيطة)

### الخطوة 1: تحسين إعدادات الجهاز/السيرفر
افتح الشاشة السوداء (Terminal) داخل مجلد المشروع ونفّذ السكريبت التالي تلقائياً:
```bash
bash scripts/setup_host_environment.sh
```
*(يقوم هذا السكريبت بضبط الذاكرة والـ Swap والخدمات التلقائية لدعم التشغيل بنجاح).*

---

### الخطوة 2: توليد المفاتيح وكلمات السر التلقائية
نفّذ هذا الأمر التفاعلي:
```bash
python3 scripts/generate_prod_env.py
```
* سيسألك عن الدومين أو عنوان الـ IP (إذا كان على جهازك اترك الفراغ واضغط `Enter`).
* سيسألك عن كلمة سر الأدمن (يمكنك إدخال كلمة سر أو الضغط على `Enter` لتوليدها تلقائياً).
* **سيقوم السكريبت بتوليد ملف الأمان `.env` وتأمين البرنامج كلياً.**

---

### الخطوة 3: تشغيل البرنامج بكافة خدماته
نفّذ هذا الأمر النهائي لتشغيل قاعدة البيانات والواجهة الخلفية والأمامية:
```bash
docker compose up -d --build
```

🎉 **مبروك! البرنامج الآن يعمل كلياً.**
* يمكنك فتح المتصفح والدخول على: `http://localhost:8080` (أو على عنوان IP السيرفر).

---

## 🏢 كيفية تشغيل أكثر من نسخة لمشاريع/عملاء مختلفين (Multi-Instance)

إذا أردت تشغيل نسخة ثانية لمشروع جديد على نفس السيرفر بشكل معزول تماماً:

1. **انسخ مجلد المشروع إلى مجلد جديد باسم المشروع الثاني**:
   ```bash
   cp -r MyAtelier_pro MyAtelier_Client2
   cd MyAtelier_Client2
   ```

2. **غير منفذ الـ Nginx في ملف `docker-compose.yml` ليصبح منفذاً مختلفاً**:
   افتح ملف `docker-compose.yml` وغير المنفذ من `"8080:80"` إلى `"8081:80"`.

3. **شغّل سكريبت الأمان لتوليد كلمات سر ومفاتيح جديدة كلياً للمشروع الثاني**:
   ```bash
   python3 scripts/generate_prod_env.py
   ```

4. **شغل النسخة الثانية**:
   ```bash
   docker compose up -d --build
   ```
*(الآن لديك مشروعين يعملان كلياً وبشكل معزول 100%، الأول على منفذ 8080 والثاني على منفذ 8081).*

## 🤖 كيف تطلب من الـ AI تشغيل البرنامج نيابة عنك؟

إذا أردت من أي مساعد ذكاء اصطناعي (مثل Antigravity أو ChatGPT أو Claude) أن ينفذ التشغيل نيابة عنك دون أن تفعل شيئاً، انسخ له النص التالي:

> **نص التوجيه للذكاء الاصطناعي (Prompt):**
> "أنا لست مبرمجاً وأريد منك تشغيل مشروع MyAtelier Pro على هذا الجهاز لأول مرة. يرجى تنفيذ سكريبت `scripts/setup_host_environment.sh` ثم تشغيل سكريبت `scripts/generate_prod_env.py` وإنشاء ملف `.env` بأعلى درجات الأمان، ثم تشغيل المشروع باستخدام `docker compose up -d --build` والتأكد من أن جميع الحاويات تعمل بنجاح ودون أخطاء."

| :--- | :--- |
